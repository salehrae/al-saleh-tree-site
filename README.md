# شجرة أسرة الصالح

موقع ثابت (GitHub Pages) لعرض شجرة أسرة الصالح، مع لوحة تحكم لإضافة أفراد جدد أو تصحيح الأسماء.

## هيكل الملفات

```
index.html          صفحة الشجرة العامة (البحث، التوسيع/الطي، إخفاء الإناث)
admin.html          لوحة تحكم المشرف (إضافة / تصحيح) — غير مرتبطة بأي رابط ظاهر في الصفحة العامة
data/tree.json      بيانات الشجرة الأساسية (استبدلها ببياناتك الحقيقية — انظر الخطوة 1)
data/additions.json سجل الإضافات التي تُحفظ من لوحة التحكم (يبدأ فارغًا: [])
data/corrections.json سجل التصحيحات (يبدأ فارغًا: [])
.nojekyll            يمنع GitHub من معالجة الملفات عبر Jekyll
```

## الخطوة ١: استبدال بيانات الشجرة

ملف `data/tree.json` في هذه الحزمة هو عنصر نائب فقط (placeholder). استبدله بملف `tree.json` الحقيقي الذي أرسلته لك — فيه قائمة ١٨٦٩ فردًا.

## الخطوة ٢: إنشاء مستودع GitHub

١. سجّل الدخول إلى github.com (أنشئ حسابًا إن لم يكن لديك واحد).
٢. اضغط **New repository**. اختر اسمًا (مثلاً `al-saleh-tree`)، واتركه **Public** (مطلوب لتفعيل GitHub Pages مجانًا على حساب شخصي عادي).
٣. ارفع كل ملفات هذه الحزمة إلى المستودع:
   - أسهل طريقة بدون سطر أوامر: افتح المستودع على GitHub → **Add file → Upload files** → اسحب كل الملفات والمجلد `data` بالكامل → **Commit changes**.
   - أو عبر Git إن كنت معتادًا عليه:
     ```
     git init
     git add .
     git commit -m "Initial site"
     git branch -M main
     git remote add origin https://github.com/USERNAME/REPO.git
     git push -u origin main
     ```

## الخطوة ٣: تفعيل GitHub Pages

١. في المستودع: **Settings → Pages**.
٢. تحت "Build and deployment" اختر **Deploy from a branch**.
٣. اختر الفرع **main** والمجلد **/ (root)**، ثم **Save**.
٤. انتظر دقيقة أو اثنتين، ثم ستظهر رابط الموقع أعلى الصفحة بالشكل:
   `https://USERNAME.github.io/REPO/`

هذا هو رابط الشجرة العامة. صفحة المشرف على:
`https://USERNAME.github.io/REPO/admin.html`

## الخطوة ٤: ربط لوحة التحكم بالمستودع

افتح `admin.html` وعدّل السطرين في أعلى الكود:

```javascript
const GITHUB_OWNER = 'YOUR_GITHUB_USERNAME';
const GITHUB_REPO = 'YOUR_REPO_NAME';
```

غيّرهما إلى اسم المستخدم واسم المستودع الفعليين، ثم ارفع الملف المعدّل (أو عدّله مباشرة على GitHub عبر زر التعديل بالقلم).

## الخطوة ٥: إنشاء رمز وصول GitHub (Personal Access Token)

تحتاج هذا الرمز حتى تتمكن لوحة التحكم من الحفظ في المستودع. ينشئه كل شخص تثق به للإضافة بنفسه، ولا يُحفظ في أي مكان — فقط يُكتب في الصفحة وقت الاستخدام.

١. اذهب إلى <https://github.com/settings/personal-access-tokens/new>.
٢. اختر **Only select repositories** وحدد هذا المستودع فقط.
٣. تحت "Repository permissions" اختر **Contents: Read and write**.
٤. اضغط **Generate token**، وانسخه فورًا (لن يظهر مرة أخرى).
٥. الصقه في حقل "رمز الوصول في GitHub" أعلى لوحة التحكم كل مرة تريد فيها الإضافة أو التصحيح.

⚠️ هذا الرمز قوي — أي شخص يملكه يمكنه تعديل المستودع. لا تشاركه إلا مع من تثق بهم فعلاً، ولا تلصقه في أي مكان آخر غير صفحة admin.html هذه.

## ملاحظة مهمة حول الخصوصية

بما أن GitHub Pages المجاني يتطلب مستودعًا **عامًا (Public)**، فإن بيانات الشجرة (كل الأسماء) تكون متاحة للجميع عبر ملف `data/tree.json` وسجل الـ git — ليس فقط لمن يملك الرابط، بل لأي شخص يتصفح المستودع على GitHub أيضًا. هذا أكثر انكشافًا قليلاً من الإعداد السابق على Google (حيث كان الرابط غير مُدرَج لكنه كان يعمل بنفس الطريقة من ناحية عدم الحاجة لتسجيل الدخول). إن كانت هذه نقطة مهمة لك، الخيار الوحيد لإخفائها فعليًا هو مستودع خاص (private) مع خطة GitHub Pro أو أعلى.

## الخطوة ٦ (لاحقًا): ربط نطاق خاص بك

بعد شراء نطاق:

**للنطاق الرئيسي (مثل `alsaleh-family.com`):** أضف 4 سجلات A في إعدادات DNS لدى مزوّد النطاق، تشير إلى:
```
185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153
```

**للنطاق الفرعي (مثل `tree.alsaleh-family.com`) — أبسط وأسرع عادة:** أضف سجل CNAME يشير إلى `USERNAME.github.io`.

ثم في **Settings → Pages → Custom domain** بالمستودع، اكتب النطاق واضغط Save. سيُنشئ GitHub شهادة HTTPS مجانية تلقائيًا خلال دقائق إلى ساعة تقريبًا.
